# LumiaYD

Клиент Яндекс.Диска для Nokia Lumia 925 на Windows Phone 8.1 (Silverlight).

## Сборка

1. Открыть `LumiaYD.sln` в Visual Studio 2013 Community.
2. Выбрать конфигурацию `Release | ARM` (для телефона) или `Debug | ARM`.
3. Build → Rebuild Solution.
4. Готовый XAP: `LumiaYD/Bin/ARM/Release/LumiaYD_Release_ARM.xap` (путь зависит от конфигурации).

## Авторизация

Приложение использует **пароль приложения Яндекса**, а не основной пароль аккаунта.

1. Открыть Яндекс ID → Безопасность → Пароли приложений.
2. Создать пароль для приложения (тип — «Файлы» или «Другое»).
3. Ввести в приложении логин Яндекс и этот пароль.

Пароль хранится в изолированном хранилище приложения на телефоне и **не** попадает в исходники или XAP.

## Важно

- Не коммитить реальные логины, пароли, токены и сертификаты.
- `Bin/`, `obj/`, `*.suo`, `*.user` — локальные артефакты, в репозиторий не входят.
- Для сборки из сетевой папки UTM проект должен лежать на диске `Z:` (или другой букве, которую видит Windows).
